## Spring Task

Spring Task 是Spring框架提供的任务调度工具，可以按照约定的时间自动执行某个代码逻辑


### cron表达式

cron表达式其实就是一个字符串，通过cron表达式可以定义任务触发的时间。


#### 构成规则

- 分为6或7个域，由空格分隔开，每个域代表一个含义。
- 每个域的含义分别为：**秒、分钟、小时、日、月、周、年(可选)**
- `?` 代表不指定的域
- cron表达式还有表示其它含义的符号，比如月末等等。具体需要表达式时，可以直接**去生成网站生产即可**，不需要背


#### 示例

表格含义（秒 / 分钟 / 小时 / 日 / 月 / 周 / 年）：

- 秒：0
- 分钟：0
- 小时：9
- 日：12
- 月：10
- 周：?
- 年：2022

2022年10月12日上午9点整 对应的cron表达式为：

`0 0 9 12 10 ? 2022`  --> 周和日一般不会同时出现，其中一个会用 `?` 代替


#### 使用步骤

1. 导入 Maven 坐标：`spring-context`（通常项目中已包含）
2. 在启动类添加注解 `@EnableScheduling`，开启任务调度
3. 自定义定时任务类  
    需要定时执行/处理的业务逻辑代码，就写在这个定时任务类中

```java
    @Component
    public class MyTask {

        /**
         * 定时任务 每隔5秒触发一次
         */
        @Scheduled(cron = "0/5 * * * * ?")
        public void executeTask(){
            log.info("定时任务开始执行：{}", new Date());
        }
    }
```
