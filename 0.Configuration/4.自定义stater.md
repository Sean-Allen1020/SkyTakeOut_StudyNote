### 自定义依赖的制作
- 以 `阿里云文件上传工具类` 为例子

1. 创建 `aliyun-oss-spring-boot-starter` 模块
   - 在项目中创建新Module，以固定的命名规则命名
   - 删除除`pom.xml`以外的所有文件
   - 精简化`pom.xml`文件：
```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
            xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
        <modelVersion>4.0.0</modelVersion>
        <parent>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-parent</artifactId>
            <version>4.0.1</version>
            <relativePath/> <!-- lookup parent from repository -->
        </parent>
        <groupId>com.aliyun.oss</groupId>
        <artifactId>aliyun-oss-spring-boot-autoconfigure</artifactId>
        <version>0.0.1-SNAPSHOT</version>
        <name>aliyun-oss-spring-boot-autoconfigure</name>
        <description>aliyun-oss-spring-boot-autoconfigure</description>

        <properties>
            <java.version>21</java.version>
        </properties>

        <dependencies>
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-starter</artifactId>
            </dependency>

        </dependencies>
    </project>
```
--------------------------------------------------------------------------------------
1. 创建 `aliyun-oss-spring-boot-autoconfigure` 模块，在 `starter` 中引入该模块
   - 在项目中创建新Module，以固定的命名规则命名
   - 删除除`pom.xml`和`src文件夹`以外的所有文件
   - 精简化`pom.xml`文件，内容同上
   - 在`starter`的`pom.xml`中引入该配置模块的依赖：
```xml
    <dependency>
        <groupId>com.aliyun.oss</groupId>
        <artifactId>aliyun-oss-spring-boot-autoconfigure</artifactId>
        <version>0.0.1-SNAPSHOT</version>
    </dependency>
```
--------------------------------------------------------------------------------------
3. 在 `aliyun-oss-spring-boot-autoconfigure` 模块中定义自动配置功能，并定义自动配置文件 `META-INF/spring/xxxx.imports`
