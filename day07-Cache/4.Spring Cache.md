### Spring Cache

- 实现了基于**注解**的缓存功能，提供了一层抽象，底层可以切换不同的缓存实现：
  - EHCache
  - Caffeine
  - Redis

> 需要用哪种缓存，就引入对应的依赖即可

-----------------------------------
- 常用注解：
| 注解           | 说明                                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------------------------- |
| @EnableCaching | 开启缓存注解功能，通常加在启动类上                                                                                     |
| @Cacheable     | 在方法执行前先查询缓存中是否有数据，如果有数据，则直接返回缓存数据；如果没有缓存数据，调用方法并将方法返回值放到缓存中 |
| @CachePut      | 将方法的返回值放到缓存中                                                                                               |
| @CacheEvict    | 将一条或多条数据从缓存中删除                                                                                           |

-----------------------------------
- 依赖引入：
```xml
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-cache</artifactId>
    </dependency>
```
`@Cacheable` or `@CachePut `：`(value = "userCache", key = "#user.id")`

> value: 对值的描述
> CachePut 的 key:   键的取名规则，也可写成 `result.xx`
> 最终生成的键为：`userCache::id`

-----------------------------------
- 各情况注解写法示例：
```java
@CachePut(value = "userCache", key = "#user.id")    //无论缓存是否存在，都存缓存
@CachePut(value = "userCache", key = "#result.id")

@Cacheable(value = "userCache", key = "#id")    

@CacheEvict(value = "userCache", key = "#id")   //单个删除
@CacheEvict(value = "userCache", allEntries = true)   //批量删除
```

----------------------------------
- 缓存参数配置(基于 Redis ):
```java
    @Configuration
    public class CacheConfiguration {

        @Bean
        public RedisCacheManager redisCacheManager(RedisConnectionFactory redisConnectionFactory) {

            //默认缓存配置：全局有效时间10分钟，不缓存null，用 JSON 序列化 value
            RedisCacheConfiguration defaultConfig = RedisCacheConfiguration.defaultCacheConfig()
                    .entryTtl(Duration.ofMinutes(20))
                    .disableCachingNullValues()
                    .serializeValuesWith(
                            RedisSerializationContext.SerializationPair.fromSerializer(
                                    new GenericJackson2JsonRedisSerializer()
                            )
                    );

            return RedisCacheManager.builder(redisConnectionFactory)
                    .cacheDefaults(defaultConfig)
                    .build();
        }
    }
```
